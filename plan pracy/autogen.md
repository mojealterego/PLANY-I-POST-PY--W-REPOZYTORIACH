# AUDYT 362 — autogen

## Status
Audyt wykonany. Microsoft AutoGen jest w maintenance mode i kieruje nowe projekty do Microsoft Agent Framework.

## Ustalenia
Framework wieloagentowy z Core, AgentChat, Extensions, Studio i Bench; Python 3.10+, integracje modeli, MCP i code execution.

## Ryzyka
Autonomiczne narzędzia/MCP, wykonywanie kodu, agent loops i sekrety. AutoGen Studio nie jest deklarowane jako production-ready.

## Plan prac
Utrzymywać jako materiał migracyjny/referencyjny, zmapować wzorce do Microsoft Agent Framework, zachować testy bezpieczeństwa i nie rozwijać forkowego produktu bez decyzji.

## Kryterium zakończenia
Mapa migracji i kompletna klasyfikacja maintenance/reference.
