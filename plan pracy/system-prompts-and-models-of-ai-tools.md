# Plan pracy — system-prompts-and-models-of-ai-tools

## Stan audytu
**AUDYT WSTĘPNY ZAKOŃCZONY — 2026-09-11**

## Ustalenia
- Repozytorium jest dużym katalogiem materiałów dotyczących system prompts i modeli narzędzi AI.
- README deklaruje ponad 30 000 linii materiałów.
- Dokumentacja zawiera liczne zewnętrzne linki, sponsorów, kanały społecznościowe, elementy finansowe i marketingowe.
- Charakter projektu jest przede wszystkim dokumentacyjno-referencyjny, a nie klasycznie aplikacyjny.

## Ryzyka
1. Konieczna jest weryfikacja pochodzenia i aktualności materiałów.
2. Należy rozdzielić materiały referencyjne od treści promocyjnych.
3. Należy ustandaryzować strukturę metadanych i wersjonowanie wpisów.
4. Należy zdefiniować politykę polonizacji: tłumaczyć opis/indeks, ale nie niszczyć oryginalnych artefaktów technicznych.
5. Należy wykryć duplikaty, nieaktualne modele i martwe odnośniki.

## Plan implementacji
1. Zindeksować wszystkie katalogi i źródła materiałów.
2. Zbudować schemat metadanych: narzędzie, model, dostawca, wersja, data, źródło, typ artefaktu.
3. Wykryć duplikaty i niespójne nazewnictwo.
4. Zweryfikować linki oraz aktualność informacji.
5. Oddzielić treści techniczne od sponsorowanych i promocyjnych.
6. Zbudować polski indeks i nawigację.
7. Zachować oryginalne artefakty techniczne tam, gdzie tłumaczenie zmieniałoby znaczenie.
8. Dodać automatyczną kontrolę jakości linków i formatowania.
9. Uporządkować README i strukturę repozytorium.

## Kryterium zakończenia
Spójny, przeszukiwalny, aktualny katalog referencyjny z kontrolą źródeł, bez martwych sekcji i z polską warstwą nawigacyjną.
