# AUDYT 357 — ext-skills

## Status
Eksperymentalne repozytorium grupy roboczej Skills Over MCP. Nie jest oficjalną specyfikacją MCP.

## Ustalenia
Repo definiuje problematykę dostarczania skills przez MCP Resources, routing master/category/deep skills, threat model, decyzje i wyniki eksperymentalne. Źródłem prawdy dla SEP-2640 jest właściwy PR upstream.

## Ryzyka
Rozjazd kopii z canonical SEP, zaufanie do zewnętrznych skills, dynamiczne aktualizacje i uprawnienia wieloserwerowej orkiestracji.

## Plan prac
Utrzymywać jako materiał badawczy; śledzić canonical SEP, testować modele discovery/update, modelować provenance i RBAC oraz przygotować polską dokumentację.

## Kryterium zakończenia
Audytowalna synchronizacja z upstream i jednoznaczne oznaczenie treści eksperymentalnych.
