# Audyt: Duix-Mobile

## Stan
AUDYT — cross-platform SDK AI avatar dla Android/iOS/tablet/VR/IoT; on-device avatar, LLM/ASR/TTS integracje, streaming audio, barge-in i lip-sync.

## Ryzyka
Deklaracje niskich opóźnień wymagają reprodukcji. Kluczowe są dane głosowe/wizerunkowe, provenance avatarów, pamięć urządzenia, natywne biblioteki oraz bezpieczne integracje z własnymi providerami AI.

## Priorytet
KRYTYCZNY.

## Kolejność
Model/data provenance → native lifecycle → audio/privacy → provider contracts → performance benchmarks → device matrix → polonizacja.

## Kryterium zakończenia
Zweryfikowane benchmarki, bezpieczne przetwarzanie audio/wizerunku i reprodukowalne buildy Android/iOS.
