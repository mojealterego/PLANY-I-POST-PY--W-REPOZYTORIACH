# Audyt 330 — Cz-owiek-Roku-Film

## Stan
AUDYT ZAKOŃCZONY — główne repozytorium produkcji filmu AI.

## Ustalenia
README ustanawia Single Source of Truth dla adaptacji filmu „Człowiek Roku”. Zawiera master state, story bible, chronologię, source catalog, visual language, tattoo bible, pipeline AI/Picsart, mapę 74 scen, bibles postaci i decision log. Kluczowa zasada rozdziela SOURCE, ADAPTATION, FILM DECISION, REFERENCE LOCK, CONTINUITY LOCK i UNVERIFIED REFERENCE.

## Ryzyka
Błędy continuity; mieszanie źródeł z decyzjami; provenance materiałów; spójność postaci/tatuaży; generacja AI i montaż.

## Priorytet
KRYTYCZNY.

## Kolejność prac
1. Utrzymać repo jako kanoniczny ledger.
2. Walidować source-lock i continuity-lock.
3. Zautomatyzować kontrolę spójności scen/postaci.
4. Dopiero potem rozwijać pipeline generacji.

## Kryterium zakończenia
