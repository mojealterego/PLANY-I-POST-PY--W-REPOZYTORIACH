## Stan faktyczny
GitHub Pages zawiera indeks i tematy dotyczące fingerprint browsers, checkerów fingerprintu, SMS, proxy, poczty tymczasowej, kart wirtualnych, danych testowych, cloud phone i browser automation. README rozdziela artykuły, dane strukturalne, źródła, metodologię i changelog.

## Ryzyka
Tematy fingerprint/proxy/SMS mogą służyć zarówno legalnej QA, jak i obchodzeniu mechanizmów platform. Dane rynkowe szybko się zmieniają; kluczowe są provenance i neutralne opisy.
