# Audyt 333 — rust-sdk

## Stan
AUDYT ZAKOŃCZONY — SDK Rust.

## Ustalenia
Repozytorium stanowi bibliotekę/SDK Rust. Dalsza ocena powinna koncentrować się na publicznych API, typach, błędach, kompatybilności wersji Rust i testach integracyjnych.

## Ryzyka
Breaking changes; bezpieczeństwo zależności Cargo; obsługa błędów i transportu; provenance release.

## Priorytet
ŚREDNI/WYSOKI.

## Kolejność prac
1. Zweryfikować Cargo.toml/workspace.
2. Zmapować publiczne API.
3. Uruchomić testy i clippy.
4. Zweryfikować release policy.

## Kryterium zakończenia
Stabilny kontrakt API, aktualne zależności i testy.
