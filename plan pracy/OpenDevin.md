# Audyt: OpenDevin

## Stan
AUDYT — repozytorium agentowe powiązane z OpenHands/Devin-style coding workflows; wymaga kontroli aktualnego branchu i zakresu.

## Ryzyka
Agenty programistyczne mogą wykonywać kod, operacje plikowe i sieciowe. Kluczowe są sandboxing, approval, workspace isolation i sekret management.

## Priorytet
KRYTYCZNY.

## Kolejność
Runtime → sandbox → tools → permissions → network → tests → provenance.

## Kryterium zakończenia
Brak niekontrolowanego wykonania poza workspace i kompletne testy granic uprawnień.
